# スカルキング ルール仕様（実装用に固定した版）

このドキュメントは実装の唯一の正とする。判断が割れた箇所は「決定」として理由付きで残す。
根拠:

- [BGA 公式ルール要約（英語）](https://en.doc.boardgamearena.com/Gamehelpskullking)
- [リゴレ 日本語ルール（FAQ 付き）](https://www.rigoler.jp/2022/02/08/sk/)
- [Grandpa Beck's Games 公式](https://www.grandpabecksgames.com/pages/skull-king)

## 1. ゲームの流れ

- 2〜6 人。10 ラウンド。
- 各ラウンド: カードを配る → 全員ビッド → トリックを手札枚数ぶん → 得点計算。
- ラウンド N では各プレイヤーに N 枚配る。
- 第 1 ラウンドの開始プレイヤーは任意（実装ではランダム）。以降は毎ラウンド左隣（席順 +1）へ移る。
- 10 ラウンド終了時に合計点が最も高いプレイヤーの勝ち。同点は引き分け（複数勝者）。

## 2. カード構成（基本 70 枚）

| 種別 | 内訳 |
| --- | --- |
| 色カード 56 枚 | 緑・黄・紫・黒 各 1〜14 |
| 海賊 5 枚 | ロージー、ベント、ラスカル、ファニータ、ハリー |
| ティグレス 1 枚 | 出したときに「海賊」か「逃走」を選ぶ |
| スカルキング 1 枚 | |
| 人魚 2 枚 | |
| 逃走 5 枚 | |
| 拡張 | クラーケン 1、白クジラ 1、略奪品 2（計 74 枚） |
| 合計 | 基本 70 枚／拡張込み 74 枚 |

黒（ジョリーロジャー）は切り札。色カードの中では最強。

## 3. ビッド

- 全員が同時に公開する（実装上は全員の入力が揃うまで他者には非公開）。
- 0 も宣言できる。上限はそのラウンドの手札枚数。

## 4. トリックの裁定

### 4.1 マストフォロー

- リードが色カードなら、その色を持っているプレイヤーは必ずその色を出す。
- 持っていなければ何を出してもよい（パスは不可）。
- **特殊カード（数値なし）はマストフォローを無視していつでも出せる。**

### 4.2 リードスートの決まり方

- リードが色カード → その色がリードスート。
- リードが特殊カード → リードスートなし。全員自由。
- リードが逃走・略奪品 → **そのトリックで最初に出された色カードの色**がリードスートになる（逃走が続いた場合は次の色カードまで持ち越し）。

### 4.3 強さ

1. **クラーケン**: 出たらトリックは流れる。勝者なし。
2. **白クジラ**: 出たら特殊カードは勝てない。場の色カードのうち数字最大が勝つ（色は問わない。同数は先出し）。
   - 色カードが 1 枚も出ていなければトリックは流れ、白クジラを出した人が次のリード。
3. クラーケンと白クジラが両方出た場合、**あとから出たほうの効果だけ**を適用する。
4. 通常時:
   - 海賊 > 色カード（黒含む）
   - 人魚 > 色カード、人魚 > スカルキング
   - スカルキング > 海賊
   - 3 種が同時に出た場合は **人魚が勝つ**（人魚のスカルキング捕獲ボーナスのみ発生）。
   - 同じ強さ同士は先に出したほうが勝つ。
   - 逃走はすべてに負ける。全員が逃走なら最初に出した人が勝つ。
   - 色カードだけなら、黒があればその中で最大。黒がなければリードスートの中で最大。

### 4.4 次のリード

- トリックの勝者が次のリード。
- クラーケンで流れた場合は「クラーケンを除いて裁定したときの勝者」が次のリード。
- 白クジラで流れた場合は白クジラを出した人が次のリード。

## 5. 得点

ビッド成功時のみボーナスが入る。失敗時はボーナス全没収。

| 状況 | 得点 |
| --- | --- |
| ビッド 1 以上・的中 | +20 × ビッド数 ＋ ボーナス |
| ビッド 1 以上・失敗 | −10 × ズレた枚数 |
| ビッド 0・0 枚で終了 | +10 × ラウンド数 |
| ビッド 0・1 枚以上取った | −10 × ラウンド数 |

### ボーナス（自分が取ったトリックの中身に対して）

| 条件 | 点 |
| --- | --- |
| 色カードの 14（緑・黄・紫） | 各 +10 |
| 黒の 14 | 各 +20 |
| 海賊が人魚を取った | 人魚 1 枚につき +20 |
| スカルキングが海賊を取った | 海賊 1 枚につき +30 |
| 人魚がスカルキングを取った | +40 |
| 略奪品（拡張）を取った | 略奪品 1 枚につき +20。ただし**出した人もビッドを当てている**こと（同盟） |

## 6. 決定事項（判断が割れた点）

1. **14 のボーナスは「取ったトリックに入っていた 14」のみ。** 手札に残った 14 は加点しない（BGA の "collected in a trick" に従う）。リゴレ日本語版の記述とも矛盾しない。
2. **ビッドは全員分が揃うまで非公開。** 公開タイミングは「全員入力後」で、物理版の同時公開に相当。
3. **人魚・海賊・スカルキングが同時に出た場合のボーナスは人魚の捕獲分のみ**（BGA の明記に従う）。
4. **ティグレスは出した瞬間に海賊か逃走に確定**し、以後その扱いで裁定・ボーナス計算する（リゴレ FAQ に従う。海賊として出したティグレスをスカルキングが取れば海賊 1 枚として +30）。
5. **海賊の能力（ロージー等）は任意ルール**。ロビーの「海賊の能力」を ON にしたときだけ有効（既定は OFF）。海賊でトリックを取った人が、次のトリックの前に 1 回だけ使える。ラウンド最後のトリックではハリー以外は使えない（BGA の記述に従う）。能力で捨てた札は捨て札として保持し、山札はラウンドごとに作り直す。
6. **色カードの 14 が複数出た場合、それぞれ加算**する（1 トリックで 14 が 2 枚なら +20）。
7. **略奪品は「取った人が +20」で、条件は取った人と出した人の両方がビッド成功**していること。出した人が失敗していれば 0 点（BGA の "both make their bids" に従う）。
8. **拡張カードはロビーで個別に ON/OFF できる**。クラーケンと白クジラは同時に入れられるが、ルールブックも片方ずつを勧めている。

## 7. 未実装（段階的に追加）

- 観戦、チャット、投了、タイマー
- 途中切断した席のボット代行


## 8. 海賊の能力（任意ルール）

ロビーの「海賊の能力」を ON にしたときだけ有効。海賊のカードでトリックを取った人が、次のトリックが始まる前に 1 回だけ使える。ラウンド最後のトリックでは、ロージー・ベント・ラスカル・ファニータは使えず、ハリーだけは使える。使わない選択もできる。

| 海賊 | 効果 |
| --- | --- |
| ロージー・ディレイニー | 次のトリックのリードを任意の席にする（自分でもよい） |
| ベント・ザ・バンディット | 山札から 2 枚引いて手札に加え、手札から 2 枚捨てる |
| ラスカル・オブ・ロアタン | 0・10・20 点のサイドベット。ビッド成功で加点、失敗で同じだけ減点 |
| ファニータ・ジェイド | 未配布の山札を見る（本人にだけ見える） |
| ハリー・ザ・ジャイアント | ビッドを ±1 する（0〜ラウンド数の範囲） |

補足:

- 能力は「海賊のカードで取った」ときだけ。タイグレスを海賊として出して取った場合は能力なし。
- サイドベットは同じラウンドで選び直した場合は最後の宣言を採用する。
- ベントで引いた札は、捨てるまで手札として扱う。捨てた札はそのラウンドの捨て札になり、山札には戻らない。
